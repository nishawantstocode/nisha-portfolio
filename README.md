# Nisha KC Portfolio

A responsive internship portfolio for Nisha KC, a Computer Information Systems student seeking software development, IT, data, and business technology internships.

## Tech Stack

- React
- Vite
- Tailwind CSS

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This project is ready to deploy on Vercel. Use the default Vite settings:

- Build command: `npm run build`
- Output directory: `dist`
